# v0.1.0-beta.14

Diese Version macht die lokale API deutlich schneller und lernt, mehrere
gleichzeitig geöffnete Steuerfälle auseinanderzuhalten. ELSTER und jede andere
Übermittlung ans Finanzamt bleiben gesperrt.

## Rund achtmal schneller je Aufruf

Jeder API-Aufruf startete bisher einen frischen PowerShell-Arbeitsprozess.
Gemessen kostete das rund 2,5 s, **bevor** die erste Zeile Fachlogik lief —
und davon entfielen etwa 1,3 s allein darauf, das 14000-Zeilen-Workerskript zu
zerlegen.

- Der API-Server hält jetzt genau **einen vorgewärmten Reservearbeiter**: einen
  PowerShell-Prozess, der Skript, Produktprofil, Assemblies und die native
  Interop-DLL bereits geladen hat und dann auf genau einen Auftrag wartet.
- Gemessen auf dem Entwicklungsrechner: **2,5 s → 0,3 s** je Aufruf.
- **Die Isolationsregel bleibt unangetastet.** Der Reservearbeiter führt seinen
  einen Auftrag aus und endet danach wie jeder andere Arbeiter. Ein wartender
  Prozess hat noch keine einzige UIA-Abfrage gestellt und kann deshalb auch
  keine vergiftete UIA-Verbindung an den nächsten Aufruf weiterreichen — genau
  die Gefahr, für die es den Prozess-pro-Aufruf überhaupt gibt.
- Vorgewärmt wird **erst nach** einer Operation, nie während einer laufenden.
  Auf einem schwachen Rechner würde der PowerShell-Start sonst mit der
  eigentlichen Fernsteuerung um die CPU streiten.
- Passt die vorgewärmte Umgebung nicht mehr zum Aufruf — etwa nach einem
  Profilwechsel —, wird der Reservearbeiter verworfen statt still das falsche
  Profil zu bedienen. Fehlt er, läuft der bisherige Kaltstart unverändert.
- Der Weg über den alternativen Windows-Desktop hat einen eigenen Prozessbaum
  und nutzt bewusst keinen Reservearbeiter.
- `/healthz` meldet unter `prewarm`, ob ein Reservearbeiter bereitsteht.

## Mehrere Steuerfälle auseinanderhalten

Einkommensteuer, Gewinnermittlung und ein älterer Fall können gleichzeitig
offen sein. Alle fallbezogenen Operationen verlangten dann zu Recht ein `hwnd` —
es gab aber keine Quelle dafür.

- Neue Operation **`instances`** (MCP: `sse_instances`) nennt je offenem
  Hauptfenster: Fenster-ID, Prozess-ID, Falldatei, Falltyp (`ESt`, `Gew`,
  `GewErfass`, …), Jahr, Startmodus, Vordergrundstatus und ob das Fenster
  einen wiederhergestellten Sitzungszustand zeigt.
- **Es wird nichts geraten.** Lässt sich die Falldatei weder aus dem
  Fenstertitel noch aus der Kommandozeile belegen, bleibt `casePath` `null`.
  Der Titel gewinnt über die Kommandozeile: er zeigt den gerade geladenen
  Fall, während die Kommandozeile nach einem Fallwechsel veraltet wäre.
- Die Operation ist rein lesend: sie ändert nichts und wechselt keinen Fokus.
  `includeHash=true` liest zusätzlich die SHA-256 jeder gebundenen Falldatei.
- Alle Kommandozeilen werden in **einer** Abfrage geholt statt je Fenster
  einzeln.

## Unterstützungsgrenze

- SteuerSparErklärung 2025 / Engine-Major 31 bleibt das einzige für Nutzer
  unterstützte Profil (`supported` und `operationAccess=full`).
- Originalfälle werden nicht geöffnet oder verändert. Sichtbare Navigation
  erfolgt ausschließlich in einer SHA-256-verifizierten Prüffallkopie.
- Es läuft weiterhin immer nur eine Operation; ein zweiter Aufruf wird sofort
  mit HTTP 409 und `code: "busy"` abgelehnt.
- Der erste sichtbare `launch` erlaubt über die direkte API-CLI weiterhin
  `--timeout-ms 280000`. Das MCP-Tool `sse_launch` behält sein
  Transportbudget von 120 Sekunden; die 280-Sekunden-Aussage gilt nicht
  für den MCP-Transport.
- MCP bleibt ein optionaler, PC-blinder Wrapper über die lokale Loopback-API;
  dieselben Operationen bleiben über die tokenladende lokale CLI verfügbar.
- Noch nie erfolgreich live belegt sind die sechs VaSt-Wege `vast_apply`,
  `vast_dialog_read`, `vast_mapping_options`, `vast_mapping_select`,
  `vast_row_details` und `vast_row_set_expanded` sowie die neue
  Mehrinstanz-Übersicht `instances`.

Der vollständige Offline-Releaseplan umfasst alle 123 geplanten Schritte:
vier serielle Build-Gates, 116 konfliktfreie Haupttests, einen exklusiven
No-Console-Test und zwei abschließende Abdeckungsbilanzen.
