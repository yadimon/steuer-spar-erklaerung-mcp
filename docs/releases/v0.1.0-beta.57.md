# v0.1.0-beta.57

Diese Beta korrigiert die Suchtreffer-Aktivierung, die sichtbare Startgrenze und den dokumentierten
Codex-Installationsweg. Empfohlen sind
direkt registriertes npm-MCP, die automatisch installierte exakt passende API
und ein separat geladener Skill. Unterstützt bleibt SteuerSparErklärung 2025
mit Engine-Major 31 einschließlich der Gewinn-Erfassung des Folgejahres.

## Korrigierte Einrichtung

Vor einem sichtbaren SSE-Start wird eine hashgebundene native Leseprobe ohne
zusätzlichen libuv-Job ausgeführt. Ein beobachteter geerbter Kill-on-close-Job
ohne stilles Breakaway weist den Start vor jedem SSE-Worker ab. Dies verhindert
einen neuen Steuerfall im kurzlebigen MCP-Prozessbaum von Codex unter Windows.
Die Anleitung beschreibt dafür eine unabhängig gestartete projektlokale API.
Die Probe liest den unmittelbaren geerbten Job und ist keine allgemeine
Überlebensgarantie für beliebige äußere Jobketten. Vorhandene SSE-Fälle und der
private Desktop-Breakaway-Vertrag behalten ihre bisherigen Wege.

Suchtreffer auf dem sichtbaren Desktop werden mit einer einzigen bewachten
Doppelklicktransaktion aktiviert. Zuvor konnten die Vorbereitungs- und
Wartephasen zweier einzelner Klickaufrufe das Doppelklickfenster überschreiten.
Zusätzlich konnte Qt eine Titelzelle als aktiv melden, obwohl ihr Klickpunkt
bereits außerhalb der sichtbaren Tabelle lag. Solche Treffer benötigen jetzt
eine vollständig sichtbare Geometrie. Die eigene Trefferliste darf dafür
genau einmal über ihren eindeutig gebundenen Schalter vergrößert werden;
anschließend werden Tabelle und Titelzelle vollständig neu gebunden.
Vordergrund-, Eingabe-, Cursor- und Verdeckungsprüfungen sowie der begrenzte
Titel- und Feldabgleich bleiben erhalten. Eine unbestätigte Suchaktivierung
beendet die Navigation, bevor ein linearer Seitenlauf beginnen kann.
Freitextziele benötigen weiterhin den exakten Seitentitel; stabile
Seitenkennungen sind zu bevorzugen.
Die UStVA-Referenz weist ausdrücklich auf die Entdeckung des vollständigen
Seitentitels einschließlich Jahr hin und verhindert das Erfinden einer
Seitenkennung aus der fachlichen Kurzbezeichnung.

- **Vollständiger Codex-Katalog:** Die Plugin-Empfehlung für Codex ist
  vorläufig ausgesetzt. Dessen Budget für Agent-Plugin-Metadaten kann aus einem
  vollständigen Serverkatalog nur einen Teil der Werkzeuge bereitstellen.
  Der direkte MCP-Weg umgeht diese Grenze. Ein erfolgreicher Handshake genügt
  als Einrichtungsnachweis erst zusammen mit dem vollständigen Modellkatalog
  und einem echten `sse_preflight`.
- **Gemeinsamer App-Server:** Die Runtime-Empfehlung liegt außerhalb von
  `AppData`. Windows kann dort neu angelegte Dateien einer paketierten
  Desktop-App in deren privaten `LocalCache` umleiten. Ein unabhängiger
  App-Server findet die scheinbar normal installierte Einstiegsdatei dann
  nicht. Eine gemeinsame lokale Dateisicht verhindert diesen Startfehler.
- **Bestehende Aufträge erhalten:** Die Umstellung beschreibt den Erhalt der
  bestätigten API-Konfiguration und Datenbereiche sowie die gezielte
  Deaktivierung allein der betroffenen Plugin-Verbindung. Andere Plugins,
  Originalfälle und Belege werden nicht neu eingerichtet.
- **Einrichtung getrennt prüfen:** Der erste Prüfauftrag startet SSE nicht.
  `setupReady=true` mit `SSE_NOT_RUNNING` kann eine erfolgreiche Einrichtung
  bei geschlossener Anwendung belegen. Der spätere Fachauftrag verwendet
  bestehende klare Freigaben für Originalarbeit, Sicherung und Speichern.

Für Claude Code bleibt das selbstenthaltene Agent Plugin unterstützt. Die
beiden npm-Pakete und das Plugin tragen dieselbe Releaseversion; MCP bindet
die API exakt. Der Operationsvertrag umfasst weiterhin 102 Operationen und
104 MCP-Werkzeuge. Der externe Dependency-Graph bleibt unverändert.

## Verifikation und Grenzen

Der Release-Gate umfasst alle 262 geplanten Schritte, darunter
244 parallele Haupttests mit konfliktbewusster Worker-Serialisierung sowie sieben exklusive
Prüfungen. Hinzu kommen Produktidentität, Plugin-Drift, Packlisten,
Publish-Dry-run und die isolierte Installation der fertigen npm-Tarballs.
Für CLI und MCP-Tool `sse_launch` gilt die gemeinsame Kaltstartfrist von
240 Sekunden.

Die Einrichtungshinweise erweitern keine Schreibfreigaben. Fallbindung,
verifizierte Sicherung, unmittelbarer Readback und ein ausdrücklicher
Speicherauftrag bleiben erforderlich. Unbekannte Schreibausgänge erlauben
keine automatische Wiederholung. Die öffentlichen BelegManager-Mutationen
bleiben gesperrt; Profil 2024 bleibt auf experimentelle Verifikation begrenzt.
ELSTER und jede Übermittlung ans Finanzamt bleiben ausgeschlossen.
