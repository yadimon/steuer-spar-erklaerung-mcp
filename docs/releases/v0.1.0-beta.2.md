# v0.1.0-beta.2

Diese Beta macht den Einstieg für Nichtentwickler eindeutig und ändert keine
ELSTER-, Versand- oder Sicherheitsgrenze.

## Neu

- kopierbarer Startprompt ganz ohne npm oder vorinstallierten MCP-Server;
- ein einzelner `npx skills`-Befehl als optionaler Komfortweg;
- vier einfache Nutzerfälle: prüfen, Belege abgleichen, kontrolliert
  korrigieren und nur einrichten;
- deutschsprachige Standardprompts und präzisere Trigger beider Skills;
- klare Positionierung als inoffizielle lokale API mit optionalem MCP-Wrapper;
- korrigierte Source-Anforderung Node.js 22+, weiterhin kein Python oder
  PowerShell 7;
- weniger als fünf Sekunden lange Demo: neutral nachgebauter Agent-Prompt und
  echte Fill-/Prüf-Frames mit einem vom Hersteller installierten Musterfall;
- zuverlässiger sichtbarer Start: Prozessstart und Fenster-/Dialog-Readback
  laufen über getrennte fensterlose Worker, ohne schwarze Konsolenfenster.

Vor dem Entpacken die separat angehängte
`steuer-spar-erklaerung.zip.sha256` gegen das portable ZIP prüfen.
