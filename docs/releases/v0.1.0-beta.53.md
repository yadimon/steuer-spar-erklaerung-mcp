# v0.1.0-beta.53

Diese Beta verbessert die vorhandenen Lese- und Navigationswege von API und
MCP sowie die Prüfung nach eigenen Änderungen. Unterstützt bleibt
SteuerSparErklärung 2025 mit Engine-Major 31. ELSTER und jede Übermittlung ans
Finanzamt bleiben gesperrt. Es kommen keine neuen Operationen hinzu.

## Gezielte Stabilisierung

- Hilfe, Symbolleisten und Schalter mit ausschließlich sichtbarem Symbol
  werden an ihre tatsächliche UI-Identität gebunden.
- Der optionale native Qt-Lesepfad prüft Scrollrichtung, vollständige
  Seitenabdeckung und die Wiederherstellung der Ausgangsposition.
- Navigation per pageId berücksichtigt eindeutig zugeordnete dynamische
  Seitentitel. Ein Seitentitel allein genügt weiterhin nicht als Nachweis
  eines vollständigen Positionsbestands.
- Positionsübersichten dürfen nach einem Seitenwechsel innerhalb derselben
  ursprünglichen Frist höchstens drei frische Snapshots abwarten.
  Unvollständige oder widersprüchliche Bestände bleiben gesperrt.
- Native Belegänderungen warten nach dem eigenen Detailabschluss auf
  vollständige sichtbare Spalten und einen semantisch passenden Zeilenbestand.
- Nach unbestätigtem Menüöffnen wird die vorhandene Bereinigung geprüft.
  Unlesbarer Zustand, verbleibende Popups oder eine unklare Fensterbindung
  erhalten den unbekannten Ausgang und den Klärungsbedarf. Es gibt keinen
  zusätzlichen Öffnungsversuch.
- Tabelleneditor-Diagnosen enthalten strukturierte, wertfreie Nachweise.
  Die Testisolation erhält unbekannte Konfigurationsbytes unverändert.

## Qualitäts- und Paketvertrag

Die Vollsuite führt alle 262 geplanten Schritte aus, darunter
244 parallele Haupttests mit konfliktbewusster Worker-Serialisierung sowie
sieben exklusive Prüfungen. Die Regressionen rufen die tatsächlichen
Produkthelfer auf und prüfen zusätzlich gezielte Gegenproben für entfernte
Sicherheitsbedingungen.

`npm run check` verlangt Audit, vollständige Offline-Suite, Plugin-Abgleich,
Release-Metadaten, Produktidentität, Paketprüfungen, Publish-Trockenlauf und
saubere Installation. Der Publish-Workflow prüft den markierten Quellstand
erneut. `npm run smoke:published` prüft die tatsächlichen Registry-Artefakte.

API, MCP und die gebündelte Plugin-Runtime tragen dieselbe Version. MCP bindet
die API exakt an diese Version. Der unterstützte npm-Kanal bleibt `latest`;
der Dependency-Graph bleibt unverändert. Der Katalog enthält weiterhin
102 API-Operationen und 104 MCP-Werkzeuge. Für CLI und MCP-Tool `sse_launch`
gilt die gemeinsame Kaltstartfrist von 240 Sekunden.

Begrenzte Busy-Retries bleiben auf validiertes HTTP 409 vor Dispatch, dieselbe
API-Identität und ein gemeinsames Zeitbudget beschränkt. Unbekannte
Schreibausgänge werden nicht automatisch wiederholt.

## Bekannte Grenzen

Der Standard-UIA-Löschweg kann bei einem vorbestehenden aktiven Tabelleneditor
vor jeder Eingabe sicher abbrechen. Der native Qt-Tabellenweg ist davon zu
unterscheiden. Der aktive Kompatibilitätsleser mit Cursorbewegung bleibt
langsam und ist weiterhin ein ausdrücklich gewählter Fallback.

Menüöffnen kann in längeren Abläufen unbestätigt bleiben. Die zusätzliche
Cleanup-Prüfung macht diesen Zustand nachvollziehbarer; sie behebt nicht die
noch ungeklärte Ursache der fehlenden Menüöffnung.

Interne Belegklassifizierung kann nach dem Öffnen eines Details wegen einer
geänderten Listenansicht abbrechen. Die neun öffentlich gesperrten
BelegManager-Vordergrundoperationen bleiben gesperrt. Positive Konto- und
Cloud-Abnahmen sowie eine erneute lückenlose Dauerabnahme aller Operationen
sind keine Zusage dieser Beta.

Qt bleibt optional und ausdrücklich zu konfigurieren. Profil 2024 bleibt
experimentell und auf Verifikation begrenzt. Die bereits dokumentierten
Zeichensatz-, Provider- und Übermittlungsgrenzen gelten weiter. Eine
bestandene Offline-Suite ersetzt keine vollständige reale Fachabnahme.
