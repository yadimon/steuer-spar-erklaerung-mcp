# v0.1.0-beta.43

SteuerSparErklärung 2025 mit Engine-Major 31 bleibt das unterstützte
Produktprofil. ELSTER und jede andere Übermittlung ans Finanzamt bleiben
gesperrt. Ebenso unverändert bleiben das Verbot automatischen Speicherns, die
Bindung an einen eindeutig bestätigten Fall, die private hashverifizierte
Sicherung vor dirty-fähiger Bedienung und der unmittelbare Readback jeder
Änderung.

**Diese Version ändert kein Produktverhalten.** Sie zeigt endlich, was das
Projekt tut.

## Das README zeigt einen echten Durchlauf

Im Repository lag seit dem ersten öffentlichen Beta eine Demoaufnahme, auf die
kein einziges Dokument verwies — sie war nie zu sehen und veraltete still. Sie
ist durch eine aktuelle ersetzt, und das README bindet sie jetzt ein.

Zu sehen ist ein Auftrag in einem Satz: vier neue Eingangsrechnungen aus einem
Belegordner als Betriebsausgaben eintragen, jede auf ihre passende Kostenart,
speichern — und zum Schluss die Umsatzsteuer-Voranmeldung für den Monat zeigen.
Der Auftrag endet ausdrücklich mit „nichts an ELSTER senden", und genau das
passiert auch nicht.

Die Aufnahme läuft gegen einen erfundenen Beispielfall. Es sind keine echten
Steuerdaten darin, und der Dateipfad der Aufnahmemaschine ist entfernt.

## Zeitgrenzen

Für CLI und MCP-Tool `sse_launch` gilt unverändert eine gemeinsame
Kaltstartfrist von 240 Sekunden; die übrigen Toolbudgets und alle dauerhaften
Sicherheitsgrenzen bleiben operationsspezifisch. Unbekannte Versionen und
unklare Ressourcenbindungen bleiben fail-closed.

## Verifikation vor Veröffentlichung

Der vollständig bestandene Suite-Plan umfasst alle 161 geplanten Schritte,
darunter 148 parallele Haupttests mit konfliktbewusster Worker-Serialisierung
und vier exklusive Windows-Prozess-/Packaging-Gates. Der Operationskatalog
bleibt bei 100 Operationen und 101 Werkzeugen; das Produktprofil bleibt auf
Build `31.0.2.0` nachverifiziert. Das gebaute Paket wurde zusätzlich aus einer
frischen Installation heraus geprüft.
